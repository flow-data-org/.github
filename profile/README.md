<p align="center"><b>Данные и ИИ-инженерия: курсы, продукты и общие шаблоны.</b></p>

## Что мы делаем

| Направление | О чём | Префикс репозитория |
|---|---|---|
| 🎓 **Курсы** | Практическое обучение дата- и ИИ-инженерии | `course-*` |
| 🧩 **Продукты** | Инструменты для работы с данными, например семантический слой | `product-*` |
| 📐 **Шаблоны** | Заготовки репозиториев, процессов и правил работы с агентами | `flow-data`, `templates` |

## Репозитории

| Репозиторий | Описание | Статус |
|---|---|---|
| [flow-data](https://github.com/flow-data-org/flow-data) | Главная страница проекта, общие правила и шаблоны | активен |
| [course-ai-data-engineer](https://github.com/flow-data-org/course-ai-data-engineer) | Курс по ИИ- и дата-инженерии | в разработке |
| `product-semantic-layer` | Семантический слой для данных | планируется |
| `templates` | Общие шаблоны репозиториев | планируется |

Один проект — один репозиторий. Монорепозитория нет.

## Принципы

- **Безопасность по умолчанию:** секреты не попадают в репозитории (gitleaks, pre-commit, GitHub Secrets).
- **Общие правила, свои исключения:** [центральные правила](https://github.com/flow-data-org/flow-data/blob/main/docs/agent-workflow.md) подключают все репозитории и могут переопределять отдельные пункты.
- **Начинаем с минимума**, новые проекты добавляем по мере развития.

## Как помочь

Заводите Issues и Pull Request в нужном репозитории. О проблемах безопасности — по инструкции в [SECURITY.md](https://github.com/flow-data-org/.github/blob/main/SECURITY.md).
